Authentication
All API endpoints require authentication. Two methods are supported:

1. API Key — pass X-API-Key: <key> header, or ?api_key=<key> query param. Full access.
2. Session Cookie — log in at /login and use the session. Role-based access applies.

Non-mod users can only access their own data. Mods have full access.
Loans
GET /api/loans
List loans. Non-mods can only query their own loans.
ParamTypeDescription
lenderoptionalFilter by lender username
borroweroptionalFilter by borrower username
statusoptionalFilter by status: confirmed, partially_repaid, repaid, unpaid, refunded, disputed. Comma-separate for multiple.
searchoptionalSearch lender/borrower names (mod only)
limitoptionalMax results (default 200)
POST /api/loans
Create a new loan. Requires lender or mod role.
FieldTypeDescription
borrowerrequiredBorrower Reddit username (strip u/ prefix)
amountrequiredLoan amount (number)
currencyoptional3-letter currency code (default: USD)
thread_urloptionalReddit thread URL
notesoptionalPrivate note (max 500 chars, not shown to borrower)
GET /api/loans/{loan_id}
Get a single loan by ID (numeric db_id or LC-XXXXXX loan_id). Non-mods must be the lender or borrower.
POST /api/loans/{loan_id}/paid
Record a repayment on a loan.
FieldTypeDescription
lenderrequiredLender username (must match loan record)
amountrequiredAmount paid
currencyrequiredCurrency (must match loan)
POST /api/loans/{loan_id}/unpaid
Mark a loan as unpaid. Body: {"lender": "username"}
POST /api/loans/{loan_id}/refunded
Cancel/refund a loan. Body: {"lender": "username"}
POST /api/loans/{loan_id}/dispute
Flag a loan for mod review. Body: {"borrower": "username"}
POST /api/loans/{loan_id}/dispute/resolve
Resolve a disputed loan. Mod only.
FieldDescription
final_statusunpaid (borrower defaulted) or confirmed (false dispute)
PATCH /api/loans/{loan_id}/notes
Update a loan's private note. Lender or mod only. Body: {"notes": "text"}
Users
GET /api/users/{username}
Get a user's stats and recent loans. Non-mods can only fetch their own profile. Returns: loans_as_borrower, loans_as_lender, amount_borrowed, amount_repaid, unpaid_loans, recent_loans.
GET /api/users/{username}/profile
Public borrower profile — available to any authenticated user (for vetting). Returns health stats without full loan details.
Stats
GET /api/stats
Global loan statistics. Returns totals by status, volume, repayment rate, and new-this-week count.
GET /api/stats/lender/{lender}
Per-lender stats: total/active/unpaid/repaid loans, total lent, outstanding, recovered, unique borrowers, this_month, avg_loan_size.
Admin (Mod only)
GET /api/admin/roles
List all users with assigned roles.
POST /api/admin/roles/{username}
Assign a role to a user. Body: {"role": "mod"|"lender"|"borrower"}
POST /api/admin/migrate
Re-run database schema migrations (idempotent, safe to call multiple times).
