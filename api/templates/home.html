Bot commands

Everyone

$login

Set up or recover your dashboard account.

$stats u/name

Check a Reddit account's age and activity.

$logi u/name

See a lender's record and rank.

$help

List every command.

Lenders Verified Lender flair

$fund REQ-0042

Fund a request.

$loan 100 USD

Offer a loan. The borrower confirms it.

$paid_with_id ID 50 USD

Record a repayment.

$unpaid ID

Mark a loan unpaid.

$refunded ID

Cancel a loan.

Borrowers

$confirm

Accept a loan offer once you've received the money.

Every command also works with ! instead of $.

LoanCentral keeps records only. It doesn't lend, hold or send money.
