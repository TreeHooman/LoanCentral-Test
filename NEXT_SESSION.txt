TO WIRE UP REDDIT OAUTH:
1. Go to https://www.reddit.com/prefs/apps → Create App → type: "web app"
2. Set redirect URI: http://localhost:5000/auth/callback
3. Add to .env:
   DASHBOARD_CLIENT_ID=<your_client_id>
   DASHBOARD_CLIENT_SECRET=<your_client_secret>
   DASHBOARD_REDIRECT_URI=http://localhost:5000/auth/callback
   DASHBOARD_URL=http://localhost:5000

TO RUN THE SERVER:
1. Open pgAdmin (keep it open so DB is available)
2. Open PowerShell in C:\LB drive
3. Run: python run_dev.py
4. Go to: http://127.0.0.1:5000
