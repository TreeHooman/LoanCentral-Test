## WHAT WAS DONE THIS SPRINT

### T1 — Verified Lender Badge
- dashboard_lender.html: badge "✓ Verified Lender" shown in header when
  session.verified_lender is True. "Apply for Verification" button hidden
  when already verified (no point applying again).
- app.py: /dashboard/lender now passes verified_lender=session.get("verified_lender")
  to the template.
- services.py: get_user_profile() now also queries user_roles to include
  verified_lender (bool) and reddit_username in the returned dict.
- profile.html: loadProfile() injects verified lender badge and linked
  reddit username into the profile title when p.verified_lender is true.
  Profile title element given id="p-profile-title" for targeting.

### T2 — Notification Delivery for Key Events
Previously only verification grant/revoke fired notifications.
Now four additional events trigger create_notification() in services.py:
- create_loan    → lender: "Loan recorded", borrower: "New loan confirmed"
                   type: loan_confirmed (both)
- mark_repaid    → lender: "Payment received"
                   type: payment_received
- mark_unpaid    → borrower: "Loan marked unpaid"
                   type: loan_unpaid
- dispute_loan   → lender: "Dispute opened on your loan"
                   type: dispute_opened

### T3 — OTP Rate Limiting
- app.py: _otp_check_rate(ip) helper — in-memory per-IP counter,
  5 attempts per 15-minute window, stale entries cleaned on each check.
  Constants: OTP_RATE_MAX=5, OTP_RATE_WINDOW=900 (15 min).
- /api/auth/borrower/claim and /api/auth/borrower/verify both return 429
  with "Too many attempts. Please wait 15 minutes and try again." when
  the IP is over the limit.

### T4 — Borrower Verification Application UI
- dashboard_borrower.html: "Apply for Lender Verification" button added
  to header. Opens borrowerVerificationModal with public + private note
  fields. Calls /api/verification/apply (same endpoint lender dashboard uses).

### Reminders Widget
- Already fully wired (no changes needed). loadReminders() in lender
  dashboard calls /api/reminders, renderDueAlerts() shows overdue/due-soon
  loans at top of dashboard.
